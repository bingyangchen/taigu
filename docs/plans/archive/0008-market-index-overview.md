# 0008 大盤指數總覽

## 目標

使用者在儀表板看見加權指數與櫃買指數的摘要後，從同一個入口進入大盤指數頁，就能在同一畫面讀到兩個指數的點數與走勢，並一起切換到想看的期間。

## 範圍

- 將儀表板的大盤指數摘要合為一個連結。
- 重新設計大盤指數頁的寬版與窄版，讓兩張走勢圖共用「今日」、「歷史」與歷史區間。

## 設計稿

[大盤指數設計稿](../../../design/market-index-overview.html)可操作儀表板入口、返回路徑、兩張圖表和共用期間控制，也可以預覽各種行情狀態。稿內行情均為模擬資料。

## Spec 變更

### market-data.md

#### MKT-R13 儀表板的大盤指數卡片

儀表板把兩筆行情摘要放在同一個連結裡。

儀表板顯示一張「大盤指數」卡片，內含加權指數與櫃買指數各自的盤中走勢與摘要（最新指數、漲跌點數與漲跌幅）。行情日期的標示方式、漲跌幅缺值時的顯示方式，以及摘要的數字格式都依 MKT-R14。使用者可以點選卡片內任一位置，或用鍵盤選取卡片並按 Enter，前往 `/market-index`。

前端查詢兩個指數的盤中行情時，「大盤指數」卡片依查詢結果顯示以下內容，其餘儀表板內容照常顯示（service worker 以 cache 回應的情況依 MKT-R14）：

- 前端第一次查詢、還沒有結果時，卡片在圖表與數值的位置顯示載入狀態。
- 查詢成功但沒有行情時，卡片顯示「目前沒有行情」。
- 查詢失敗而卡片已有行情時，卡片保留已顯示的行情，並標示「更新失敗，顯示上次行情」。
- 查詢失敗而卡片沒有行情時，卡片顯示「行情讀取失敗」。

- MKT-R13.1 休市的日子
  - 前提：今天是週六，加權指數與櫃買指數最後記錄的都是週五的盤中走勢，加權指數週五最後一點是 22,880 點，漲跌是 -120 點。
  - 動作：使用者開啟儀表板。
  - 結果：「大盤指數」卡片只顯示一個行情日期，日期是週五。兩個摘要都顯示週五的盤中走勢，加權指數的最新指數與漲跌為 22,880 點與 -120 點。
- MKT-R13.2 兩筆行情共用同一個入口
  - 前提：儀表板顯示兩個指數的行情摘要。
  - 動作：使用者分別點選加權指數摘要、櫃買指數摘要、卡片標題和兩筆摘要之間的留白，再用 Tab 鍵移到卡片並按 Enter。
  - 結果：每次都進入 `/market-index`，整張卡片在鍵盤導覽順序中只出現一次。
- MKT-R13.3 首次查詢期間
  - 前提：前端尚未取得任何一個指數的行情，盤中行情查詢還沒結束。
  - 動作：使用者開啟儀表板。
  - 結果：「大盤指數」卡片在圖表與數值的位置顯示載入狀態，投入金額等其餘儀表板內容照常顯示。
- MKT-R13.4 查詢成功但沒有行情
  - 前提：盤中行情查詢成功，兩個指數都沒有任何一點。
  - 動作：使用者開啟儀表板。
  - 結果：「大盤指數」卡片顯示「目前沒有行情」，整張卡片仍可前往 `/market-index`。
- MKT-R13.5 更新失敗時仍有行情
  - 前提：卡片已顯示兩個指數的行情，前端下一次查詢盤中行情時因連線失敗結束。
  - 動作：使用者查看儀表板。
  - 結果：卡片保留原本兩個指數的摘要與走勢，並標示「更新失敗，顯示上次行情」。
- MKT-R13.6 首次讀取失敗
  - 前提：前端尚未取得任何一個指數的行情，盤中行情查詢因連線失敗結束，service worker 也沒有 cache。
  - 動作：使用者開啟儀表板。
  - 結果：「大盤指數」卡片顯示「行情讀取失敗」，整張卡片仍可前往 `/market-index`。
- MKT-R13.7 離線開啟時使用 Cache
  - 前提：前端尚未取得任何一個指數的行情，盤中行情查詢因連線失敗結束，service worker 有上次取得的兩個指數行情。
  - 動作：使用者開啟儀表板。
  - 結果：卡片顯示 cache 裡兩個指數的摘要與走勢，並標示「更新失敗，顯示上次行情」。

#### MKT-R14 大盤指數頁

大盤指數頁同時呈現兩個指數，並由同一組控制項切換走勢。

大盤指數頁位於 `/market-index`，舊的 `/market-index/tse` 和 `/market-index/otc` 依 PUB-R5 處理。按「回儀表板」會開啟儀表板；如果使用者是從儀表板進入，按「回儀表板」或瀏覽器的上一頁回到儀表板時，儀表板回到進入前的捲動位置。

頁面依序顯示加權指數與櫃買指數的名稱、最新指數、漲跌點數、漲跌幅及各自的走勢圖，並依各指數的最新一點標示行情日期：

- 兩個指數的行情日期相同時，共用一個標籤。
- 兩個指數的行情日期不同時，分別標示。
- 有行情但沒有行情日期時，顯示「行情日期不明」。

昨收價缺值或為零，或最新指數缺值時，前端把那個指數的漲跌幅顯示成 `--`。摘要以「23,781.42」顯示最新指數，漲跌寫成「▲146.37 (0.62%)」等格式。兩張圖的右側縱軸與 tooltip 直接顯示數值，圖表的 accessible name 包含點數單位。

每次進入時，兩張圖都先顯示「今日」的盤中走勢，共用 09:00 到 13:30 的時間範圍，各自標示點數刻度與昨收線；使用者移動游標或觸控查閱某一點時的 tooltip 依 MKT-R22。切換到「歷史」時，兩張圖都顯示 MKT-R15 的收盤指數，tooltip 顯示游標或觸控位置那一筆收盤指數的日期與點數。可用寬度達 960 CSS px 時（寬版）兩張圖左右並排，小於 960 CSS px 時（窄版）上下排列。文字為預設大小且瀏覽器可用畫面為 390 × 700 CSS px 或 1280 × 800 CSS px 時，「今日」與「歷史」都不用捲動就能完整看到兩個指數的數值、圖表與控制項。可用高度不足或文字放大時，頁面可垂直捲動，讓刻度與控制項保持可讀、可操作。

使用者進入頁面時，前端就開始查詢兩個指數的歷史資料。使用者切換「今日」與「歷史」時，前端不重新查詢，每張圖依自己的資料查詢完成了沒有，顯示載入狀態或走勢。每張圖的位置依以下規則顯示：

- 前端第一次查詢、還沒有資料時，顯示載入狀態。
- 查詢成功但沒有可繪製的點時，說明目前沒有走勢。
- 查詢失敗而沒有可用資料時，顯示讀取失敗與重試入口。
- 查詢失敗而有可用資料時，保留圖表並標示更新失敗。

Service worker 因連線失敗改以 cache 回應時，這次查詢算失敗，cache 的內容算可用資料。後端在同一份回應裡回傳兩個指數的盤中行情，所以前端第一次查詢盤中行情失敗時，兩張今日走勢圖共用一個重試入口。單一指數缺少資料時，前端照常顯示另一個指數的可用資料。登入失效與 CSRF 檢查失敗依 ACCT-R5 與 ACCT-R16 處理。

- MKT-R14.1 從儀表板進入
  - 前提：兩個指數都有同一交易日的盤中走勢，加權指數的昨收價是 23,000 點，09:00 是 23,010 點，10:30 是 23,100.5 點。
  - 動作：使用者在 10:31 點選儀表板的「大盤指數」卡片，接著按「回儀表板」或瀏覽器的上一頁。
  - 結果：畫面換到 `/market-index`，「今日」為選取狀態，畫面同時顯示行情日期、兩個指數的摘要與走勢。加權指數顯示「23,100.5」與「▲100.5 (0.44%)」，圖上有 09:00 與 10:30 的資料點。回到儀表板後，捲動位置與進入前相同。
- MKT-R14.2 直接開啟大盤指數頁
  - 前提：使用者已登入，兩個指數都有盤中走勢。
  - 動作：使用者開新分頁直接開啟 `/market-index`，接著按「回儀表板」。
  - 結果：大盤指數頁顯示兩張今日走勢圖。按「回儀表板」後開啟儀表板。
- MKT-R14.3 不用捲動就看到兩張圖
  - 前提：兩個指數都有盤中走勢與收盤指數，瀏覽器可用畫面分別為 390 × 700 與 1280 × 800 CSS px，文字為預設大小。
  - 動作：使用者開啟大盤指數頁，接著切換到「歷史」。
  - 結果：窄版由上而下、寬版由左而右顯示兩個指數。切換前後，兩組數值、右側的點數刻度、時間或日期刻度，以及共用控制項都完整出現在不用捲動的畫面裡。
- MKT-R14.4 縮短視窗或放大文字
  - 前提：兩張走勢圖都有資料。
  - 動作：使用者把可用畫面縮至 320 × 568 CSS px，或在窄版將文字放大至 200%。
  - 結果：使用者可以垂直捲動到兩組數值及圖表，仍能操作控制項，頁面沒有橫向捲動。
- MKT-R14.5 一張圖表先取得資料
  - 前提：加權指數的歷史資料已載入，櫃買指數的歷史資料仍在載入且沒有 cache。
  - 動作：使用者查看「歷史」。
  - 結果：加權指數顯示歷史走勢，櫃買指數的圖表位置顯示載入狀態。
- MKT-R14.6 一個指數沒有可繪製的資料
  - 前提：加權指數有可繪製的歷史資料。櫃買指數有最新盤中指數，行情日期不明，歷史查詢成功但沒有收盤指數。
  - 動作：使用者查看「歷史」。
  - 結果：加權指數顯示歷史走勢，櫃買指數的摘要仍顯示最新指數，圖表位置提示目前沒有歷史走勢。
- MKT-R14.7 一個指數讀取失敗
  - 前提：加權指數有可繪製的歷史資料，櫃買指數首次讀取失敗，沒有可用的歷史資料。
  - 動作：使用者在櫃買指數的圖表位置按「重試」。
  - 結果：前端重新查詢櫃買指數的歷史資料，加權指數的歷史走勢持續可見。
- MKT-R14.8 更新失敗時仍有可用資料
  - 前提：櫃買指數有可用的歷史資料，但前端下一次查詢櫃買指數的歷史資料時失敗。
  - 動作：使用者查看「歷史」。
  - 結果：櫃買指數保留原有走勢，並標示「更新失敗，顯示上次取得的走勢」。
- MKT-R14.9 兩個指數的行情日期不同
  - 前提：加權指數的最新行情是 11 月 24 日，櫃買指數的最新行情是 11 月 23 日。
  - 動作：使用者查看儀表板，再進入大盤指數頁並切換到「歷史」。
  - 結果：兩個頁面都分別標示各指數的行情日期；櫃買指數的最新盤中指數畫在 11 月 23 日。
- MKT-R14.10 首次讀取兩個指數的盤中行情失敗
  - 前提：前端尚未取得任何一個指數的行情，且本次盤中行情查詢因連線失敗結束，service worker 也沒有 cache。
  - 動作：使用者在大盤指數頁按「重試」。
  - 結果：兩張圖共用一個重試入口，前端重新送出一筆盤中行情查詢。
- MKT-R14.11 窄版保留加號選單
  - 前提：使用者以窄版開啟大盤指數頁。
  - 動作：使用者展開加號選單。
  - 結果：選單提供 REC-R10 的四個選項，收合後可以繼續查閱兩張走勢圖。
- MKT-R14.12 行情回應缺少個別日期
  - 前提：盤中行情回應有兩個指數的點數，只提供共用的日期。兩個指數最新一筆已保存的收盤指數都來自上一個交易日。
  - 動作：使用者查看儀表板，再進入大盤指數頁並切換到「歷史」。
  - 結果：兩個頁面都顯示最新指數及「行情日期不明」。歷史走勢的最後一點仍是上一個交易日的收盤指數。
- MKT-R14.13 開啟舊的大盤指數網址
  - 前提：大盤指數頁的網址為 `/market-index`。
  - 動作：使用者分別開啟 `/market-index/tse` 和 `/market-index/otc`。
  - 結果：兩個網址都顯示 PUB-R5 的找不到頁面。

#### MKT-R15 大盤指數頁的歷史走勢

歷史區間一次套用到兩個指數。

在大盤指數頁選「歷史」時，前端把每個指數的收盤指數依日期排序，畫成各自的走勢圖。有最新盤中指數與它的行情日期時，前端把這筆盤中指數畫在行情日期的位置；如果那一天已經保存了收盤指數，就只畫最新盤中指數，不畫那天的收盤指數。兩張圖共用一組區間控制項，使用者選「1M」、「1Q」、「1Y」時，前端分別從每個指數可用的資料取最近 30、91、365 個點，選「ALL」時取全部的點。每次開啟 Taigu 後區間先是「1M」，改選後沿用該區間，直到重新開啟 Taigu。

- MKT-R15.1 切換到「歷史」與「ALL」
  - 前提：使用者這次開啟 Taigu 之後還沒選過歷史區間。加權指數保存了 36 筆收盤指數，最早一筆是 400 天前，其餘 35 筆來自最近 35 個交易日，今天的收盤指數還沒寫入，最新盤中指數是 23,100.5 點。櫃買指數保存了 50 筆收盤指數，最新一筆和最新盤中指數是同一天。
  - 動作：使用者點選「歷史」，再點選「ALL」，接著切到「今日」再切回「歷史」。
  - 結果：「1M」選取時兩張圖各有 30 個點，加權指數最後一點是今天的 23,100.5 點；點選「ALL」後，加權指數有 37 個點，首筆是 400 天前的資料，櫃買指數有 50 個點。切回「歷史」時，「ALL」仍為選取狀態。
- MKT-R15.2 歷史走勢只有最新盤中指數
  - 前提：加權指數有最新盤中指數與行情日期，歷史查詢成功但尚無收盤指數。
  - 動作：使用者點選「歷史」。
  - 結果：加權指數的走勢圖顯示最新盤中指數的單一資料點。

## 決策

### 兩張圖如何比較

- 選項
  - 將兩個指數畫在同一張圖，使用雙軸或將兩條線轉成相對變化。
  - 將兩張圖相鄰排列，時間範圍由同一組控制項決定，兩張圖各自標點數。
- 取捨：兩個指數的點數相差近兩個數量級。雙軸容易讓使用者把兩條線的交會解讀成相同點數，而相對變化圖需要轉換回原始點數才能讀出行情。
- 結論：採用相鄰的兩張圖，並讓各圖保有自己的點數刻度。
- 併入：market-data.md#MKT-R14

## 做法要點

- 由儀表板進入時，返回控制會恢復原本的儀表板位置。直接開啟詳情網址時，返回控制會開啟儀表板。
- 後端在既有盤中行情回應新增各市場的行情日期，保留原有的共用日期欄位給舊前端。新版前端遇到舊版回應時，行情仍可顯示，個別日期視為不明；這段期間歷史走勢只使用已確認日期的收盤指數。
- 前端沿用既有歷史查詢與 IndexedDB cache，並依指數分別追蹤歷史查詢的載入與結果，讓先完成的回應能立即顯示。最新盤中指數仍只在繪圖時併入歷史資料。
- 大盤指數頁沿用 REC-R10 的加號選單和 NAV-R1 的桌面側邊欄。窄版編排時將加號選單所占的空間計入可用高度。
- 兩張圖沿用 MKT-R22 的選點規則，實作時更新手動驗收清單，在同一頁檢查兩個指數的走勢圖，並確認個股詳情頁的共用行為。
