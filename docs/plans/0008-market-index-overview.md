# 0008 大盤指數總覽

## 目標

使用者在儀表板看見加權指數與櫃買指數的摘要後，從同一個入口進入大盤指數頁，就能在同一畫面讀到兩個指數的點數與走勢，並一起切換到想看的期間。

## 範圍

- 將儀表板的大盤指數摘要合為一個連結。
- 重新設計大盤指數頁的寬版與窄版，讓兩張走勢圖共用「今日」、「歷史」與歷史區間。
- 將兩個舊網址導向新的大盤指數頁。

## 設計稿

[大盤指數設計稿](../../design/market-index-overview.html)可操作儀表板入口、返回路徑、兩張圖表和共用期間控制，也可以預覽各種行情狀態。稿內行情均為模擬資料。

## Spec 變更

### market-data.md

#### MKT-R13 儀表板的大盤指數卡片

儀表板把兩筆行情摘要放在同一個連結裡。

儀表板顯示一張「大盤指數」卡片，內含加權指數與櫃買指數各自的盤中走勢、最新指數、漲跌點數與漲跌幅。日期、漲跌幅計算與摘要數字格式依 MKT-R14。使用者可以點選卡片內任一位置，或用鍵盤選取卡片並按 Enter，前往 `/market-index`。

- MKT-R13.1 休市的日子
  - 前提：今天是週六，加權指數與櫃買指數最後記錄的都是週五的盤中走勢，加權指數週五最後一點是 22,880 點，漲跌是 -120 點。
  - 動作：使用者開啟儀表板。
  - 結果：「大盤指數」卡片顯示一次週五的日期，兩個摘要都顯示週五的盤中走勢，加權指數的最新指數與漲跌為 22,880 點與 -120 點。
- MKT-R13.2 兩筆行情共用同一個入口
  - 前提：儀表板顯示兩個指數的行情摘要。
  - 動作：使用者分別點選加權指數摘要、櫃買指數摘要、卡片標題和兩筆摘要之間的留白，並用鍵盤操作一次。
  - 結果：每次都進入 `/market-index`，整張卡片在鍵盤導覽順序中只出現一次。

#### MKT-R14 大盤指數頁

大盤指數頁同時呈現兩個指數，並由同一組控制切換走勢。

大盤指數頁位於 `/market-index`，`/market-index/tse` 和 `/market-index/otc` 會導向這個網址。「回儀表板」會開啟儀表板。頁面依序顯示加權指數與櫃買指數的名稱、最新點數、漲跌點數、漲跌幅及各自的走勢圖，並依各指數的最新一點標示行情日期。兩個日期相同時共用一個標籤，日期不同時分別標示，有行情但日期不明時顯示「行情日期不明」。漲跌幅依該指數的漲跌點數除以昨收計算，昨收缺值、為零，或最新點數缺值時，對應的漲跌幅顯示缺值。

摘要以「23,781.42」顯示最新指數，漲跌寫成「▲146.37（0.62%）」等格式。兩張圖的右側縱軸與提示框直接顯示數值，圖表的無障礙名稱包含點數單位。

每次進入時，兩張圖都先顯示「今日」的盤中走勢，共用 09:00 到 13:30 的時間範圍，各自標示點數刻度與昨收線；指標與觸控的逐點查閱依 MKT-R22。兩種走勢都能用左右方向鍵逐點查閱，用 Home 或 End 移至首筆或末筆，用 Esc 清除選點。「歷史」查閱時顯示該筆日期與點數。切換到「歷史」時，兩張圖都顯示 MKT-R15 的收盤指數。可用寬度達 960 CSS px 時兩張圖左右並排，小於 960 CSS px 時上下排列。以瀏覽器可用畫面計算，在 390 × 700 CSS px 與 1280 × 800 CSS px 的預設文字大小下，兩種走勢都在首屏完整顯示兩個指數的數值、圖表與控制項。可用高度不足或文字放大時，頁面可垂直捲動，讓刻度與控制項保持可讀、可操作。

前端進入頁面時就開始讀取兩個指數的歷史資料。切換「今日」與「歷史」只切換呈現內容，讀取進度依各項資料呈現。首次讀取時，前端在尚無資料的圖表位置顯示載入狀態。查詢成功但沒有可繪製的點時，前端在該圖表位置說明目前沒有走勢。查詢失敗且沒有可用資料時，該位置顯示讀取失敗與重試入口；有可用資料時保留圖表並標示更新失敗。盤中行情由同一份回應提供，首次讀取失敗時，兩張盤中走勢圖共用一個重試入口。單一指數缺少資料時，前端照常顯示另一個指數的可用資料。登入失效與 CSRF 檢查失敗依 ACCT-R5 與 ACCT-R16 處理。

- MKT-R14.1 從儀表板進入
  - 前提：兩個指數都有同一交易日的盤中資料，加權指數的昨收是 23,000 點，09:00 是 23,010 點，10:30 是 23,100.5 點。
  - 動作：使用者在 10:31 點選儀表板的「大盤指數」卡片。
  - 結果：畫面換到 `/market-index`，「今日」為選取狀態，畫面同時顯示行情日期、兩個指數的摘要與走勢。加權指數顯示「23,100.5」與「▲100.5（0.44%）」，圖上有 09:00 與 10:30 的資料點。
- MKT-R14.2 直接開啟舊網址
  - 前提：使用者已登入，瀏覽器目前停在儀表板。
  - 動作：使用者從該分頁分別開啟 `/market-index/tse` 和 `/market-index/otc`，每次開啟後再按瀏覽器的上一頁。
  - 結果：兩個網址都導向 `/market-index`，顯示兩張今日走勢圖。按上一頁後回到儀表板。
- MKT-R14.3 首屏同時看見兩張圖
  - 前提：兩個指數都有盤中走勢與收盤指數，瀏覽器可用畫面分別為 390 × 700 與 1280 × 800 CSS px，文字為預設大小。
  - 動作：使用者開啟大盤指數頁，接著切換到「歷史」。
  - 結果：窄版由上而下、寬版由左而右顯示兩個指數。切換前後，兩組數值、右側的點數刻度、時間或日期刻度，以及共用控制項都完整出現在首屏。
- MKT-R14.4 縮短視窗或放大文字
  - 前提：兩張走勢圖都有資料。
  - 動作：使用者把可用畫面縮至 320 × 568 CSS px，或在窄版將文字放大至 200%。
  - 結果：使用者可以垂直捲動到兩組數值及圖表，仍能操作控制項，頁面沒有橫向捲動。
- MKT-R14.5 一張圖表先取得資料
  - 前提：加權指數的歷史資料已載入，櫃買指數的歷史資料仍在載入且沒有 cache。
  - 動作：使用者查看「歷史」。
  - 結果：加權指數顯示歷史走勢，櫃買指數的圖表位置顯示載入狀態。
- MKT-R14.6 一個指數沒有可繪製的資料
  - 前提：加權指數有可繪製的歷史資料。櫃買指數有最新盤中指數，行情日期不明，歷史查詢成功但沒有收盤指數。
  - 動作：使用者查看「歷史」。
  - 結果：加權指數顯示歷史走勢，櫃買指數的摘要仍顯示最新指數，圖表位置提示目前沒有歷史走勢。
- MKT-R14.7 一個指數讀取失敗
  - 前提：加權指數有可繪製的歷史資料，櫃買指數首次讀取失敗，沒有可用的歷史資料。
  - 動作：使用者在櫃買指數的圖表位置按「重試」。
  - 結果：前端重新讀取櫃買指數的歷史資料，加權指數的歷史走勢持續可見。
- MKT-R14.8 更新失敗時仍有可用資料
  - 前提：櫃買指數有可用的歷史資料，但背景更新失敗。
  - 動作：使用者查看「歷史」。
  - 結果：櫃買指數保留原有走勢，並標示「更新失敗，顯示上次取得的走勢」。

- MKT-R14.9 兩個指數的行情日期不同
  - 前提：加權指數的最新行情是 11 月 24 日，櫃買指數的最新行情是 11 月 23 日。
  - 動作：使用者查看儀表板，再進入大盤指數頁並切換到「歷史」。
  - 結果：兩個頁面都分別標示各指數的行情日期；櫃買指數的最新盤中指數畫在 11 月 23 日。
- MKT-R14.10 用鍵盤查閱圖表
  - 前提：兩種走勢各有至少兩個資料點。
  - 動作：使用者在一張圖表取得焦點後按 Home、右方向鍵，再按 Esc。接著切換走勢重做一次。
  - 結果：圖表依序顯示第一筆、第二筆資料與清除選點後的樣子；每次操作只影響目前查閱的圖表。
- MKT-R14.11 首次讀取兩個指數的盤中行情失敗
  - 前提：前端尚未取得任何一個指數的行情，且本次盤中行情查詢因連線失敗結束。
  - 動作：使用者在大盤指數頁按「重試」。
  - 結果：兩張圖共用一個重試入口，前端重新送出一筆盤中行情查詢。
- MKT-R14.12 保留行動版操作
  - 前提：使用者以窄版開啟大盤指數頁。
  - 動作：使用者展開加號選單。
  - 結果：選單提供 REC-R10 的四個選項，收合後可以繼續查閱兩張走勢圖。

- MKT-R14.13 行情回應缺少個別日期
  - 前提：盤中行情回應有兩個指數的點數，只提供共用的日期。兩個指數最新一筆已保存的收盤指數都來自前一交易日。
  - 動作：使用者查看儀表板，再進入大盤指數頁並切換到「歷史」。
  - 結果：兩個頁面都顯示最新指數及「行情日期不明」。歷史走勢的最後一點仍是前一交易日的收盤指數。

#### MKT-R15 大盤指數頁的歷史走勢


歷史區間一次套用到兩個指數。

在大盤指數頁選「歷史」時，各走勢圖畫出各自的收盤指數，並在該指數的最新盤中指數及其行情日期都可用時，把該指數畫成這一天的點。若已保存當天的收盤指數，走勢圖顯示最新盤中指數作為該日的唯一一點。前端依日期排序；沒有歷史收盤指數時，仍可畫出可用的最新盤中指數。兩張圖共用區間控制，「1M」、「1Q」、「1Y」分別從各自可用的資料取最近 30、91、365 個點，「ALL」取全部的點。每次開啟 Taigu 後區間先是「1M」，改選後沿用該區間，直到重新開啟 Taigu。

- MKT-R15.1 切換到「歷史」與「ALL」
  - 前提：使用者這次開啟 Taigu 之後還沒選過歷史區間。加權指數保存了 36 筆收盤指數，最早一筆是 400 天前，其餘 35 筆來自最近 35 個交易日，今天的收盤指數還沒寫入，目前的指數是 23,100.5 點。櫃買指數有 50 筆歷史資料，最新一筆和最新盤中指數為同一天。
  - 動作：使用者點選「歷史」，再點選「ALL」，接著切到「今日」再切回「歷史」。
  - 結果：「1M」選取時兩張圖各有 30 個點，加權指數最後一點是今天的 23,100.5 點；點選「ALL」後，加權指數有 37 個點，首筆是 400 天前的資料，櫃買指數有 50 個點。切回「歷史」時，「ALL」仍為選取狀態。
- MKT-R15.2 歷史走勢只有一筆盤中資料
  - 前提：加權指數有最新盤中指數與行情日期，歷史查詢成功但尚無收盤指數。
  - 動作：使用者點選「歷史」。
  - 結果：加權指數的走勢圖顯示最新盤中指數的單一資料點。

## 決策


### 兩張圖如何比較

- 選項
  - 將兩個指數畫在同一張圖，使用雙軸或將兩條線轉成相對變化。
  - 將兩張圖相鄰排列，時間範圍由同一組控制項決定，兩張圖各自標點數。
- 取捨：兩個指數的點數相差近兩個數量級。雙軸容易讓使用者把兩條線的交會解讀成相同點數，而相對變化圖需要轉換回原始點數才能讀出行情。
- 結論：採用相鄰的兩張圖，並讓各圖保有自己的點數刻度。
- 併入：market-data.md#MKT-R14

## 做法要點

- 由前端將舊的兩個指數網址導向 `/market-index`，使用瀏覽器歷史紀錄的取代操作。由儀表板進入時，返回控制會恢復原本的儀表板位置。直接開啟詳情網址時，返回控制會開啟儀表板。
- 後端在既有盤中行情回應新增各市場的行情日期，保留原有的共用日期欄位給舊前端。新版前端遇到舊版回應時，行情仍可顯示，個別日期視為不明；這段期間歷史走勢只使用已確認日期的收盤指數。
- 前端沿用既有歷史查詢與 IndexedDB cache，並依指數分別追蹤歷史查詢的載入與結果，讓先完成的回應能立即顯示。最新盤中指數仍只在繪圖時併入歷史資料。
- 大盤指數頁沿用 REC-R10 的加號選單和 NAV-R1 的桌面側邊欄。窄版編排時將加號選單所占的空間計入可用高度。
- 兩張圖沿用 MKT-R22 的選點規則，實作時更新手動驗收清單，在同一頁檢查兩個指數的走勢圖，並確認個股詳情頁的共用行為。
