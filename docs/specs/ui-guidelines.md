# 介面與文案規範

本文件定義 Taigu 的共通呈現原則，以及前台與後台各自的設計預設。產品定位與術語見 `product.md`，各能力的資料定義、計算規則與具體行為見相應 spec；畫面的設計流程見 `product-designer` skill。

本文件描述想要的介面，與現況的差異依 `sdd` skill 分類處理。

## 規則的適用方式

- **必須**：資料語意、可讀性、可操作性與操作安全的要求，各畫面都要遵守；需要改變時，先提出修改本文件。
- **預設**：設計時優先採用的做法。需要偏離時，提出具體原因與取捨，依 SDD 流程確認，並在相應規格中記錄例外。
- 前台與後台分別遵守各自章節，不能直接把前台字級、資訊密度或導覽套到後台。

## 共通規則

### 語言與語氣

- **必須**：介面使用台灣的繁體中文，同一個概念維持同一用詞，並使用 `product.md` 術語表與能力 spec 的名稱。
- **必須**：文案準確交代功能、資料與操作後果，不誇大功能、不承諾投資收益，也不使用投資建議口吻。
- **預設**：日常操作、資料說明與錯誤訊息務實、簡潔、友善、精確。

### 文案

錯誤與完成提示見「回饋」，破壞性操作的文案見「操作確認」。

- **預設**：用「你」稱呼使用者，法律頁面用「您」。
- **預設**：中文與英文字母或數字之間空一個半形空格，中文句子使用全形標點。
- **預設**：按鈕寫出動作與對象，例如「新增交易紀錄」，避免只寫「確定」。
- **必須**：保留使用者做決定需要的資訊，例如付款金額、續訂日期與刪除後果。

### Design Token、共用元件與 Icon

- **預設**：沿用系統字型，字型堆疊以 `frontend/src/index.scss` 為準。
- **預設**：色票、斷點與共用版面尺寸以 `frontend/src/_design_system.scss` 的 token 為來源，同類元件沿用共用樣式。
- **預設**：共用元件使用 `frontend/src/components/`，圖示使用 `frontend/src/icons/`，同一功能使用一致圖示。
- **預設**：用於比較的數字欄位靠右對齊；欄位內及會原地更新的數字使用 `font-variant-numeric: tabular-nums`。
- **預設**：金額與較大的數量使用千分位；股票代號、日期等不按數量格式處理。

### 可讀性與操作

- **必須**：一般文字與實際背景的對比至少為 4.5:1；符合 [WCAG 大字定義](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)的文字至少為 3:1。次要文字也要達標，漸層與半透明背景須依實際底色檢查。
- **必須**：資訊不能只靠顏色區分，另以文字、符號或圖示交代意義。
- **必須**：主要按鈕的操作範圍至少為 44×44px；次要圖示操作在僅使用滑鼠的環境可為 32×32px，支援觸控的環境仍至少為 44×44px。
- **必須**：互動元件能用鍵盤操作，焦點位置清楚可見，操作不能只在滑鼠移入時才可使用。
- **必須**：支援使用者放大文字與頁面，放大後主要資訊仍可閱讀，操作仍可使用。
- **必須**：對話框開啟後，焦點留在對話框內；關閉後回到合理的觸發位置。
- **必須**：尊重「減少動態效果」設定，裝飾動畫改用靜態呈現，非必要轉場改為立即切換，載入狀態仍需可辨識。
- **預設**：供查閱的資料文字可以選取與複製，拖曳或手勢區域依操作需要處理。

### 文字與圖示操作

- **預設**：主要操作與主導覽有可見文字。
- **預設**：返回、關閉等通用控制與列內次要操作可以只用圖示；既有新增浮動按鈕、後台收合導覽與處理狀態切換亦為例外。
- **必須**：純圖示操作具有 screen reader 能讀到的名稱，並在滑鼠移入或鍵盤聚焦時提供名稱提示。

### 資料語意與狀態

- **必須**：數值是否為零、缺值、不適用或尚未完成，依能力 spec 判定，不能由畫面自行混用。
- **必須**：範例資料明確標示為示意，與使用者的實際資料區分。
- **必須**：資料的日期、期間或更新狀態影響解讀時，清楚標示適用範圍；資料取得時間與來源資料時間使用不同標籤。
- **必須**：區分首次使用、查詢沒有符合結果與資料取得失敗，錯誤不能顯示成「沒有資料」。

### 回饋

#### 載入與查詢

以下查詢規則處理同一帳號內的條件切換，帳號切換的資料隔離依 `account.md`。

- **預設**：首次載入且沒有既有資料時使用 skeleton，保留與內容相符的版面空間。
- **預設**：同一條件的背景更新保留既有內容，失敗時明確提示目前仍是舊資料。
- **必須**：切換查詢條件後，若保留舊結果，控制項立即反映新選擇，結果區持續標示舊結果的適用條件與更新狀態。
- **必須**：較早查詢的回應不能覆蓋使用者最新選擇的結果。
- **預設**：切換條件後，依查詢進度更新結果區的提示：
  - 查詢發出時，立即標示更新中。
  - 查詢超過 200ms 尚未完成時，顯示轉圈提示。
  - 查詢超過 2 秒尚未完成時，顯示「仍在查詢」並提供「取消套用」入口。
  - 查詢完成後，立即呈現結果。
- **預設**：「取消套用」恢復上次成功的條件與結果；失敗或逾時則保留新選擇，舊結果繼續標示原條件，並提供錯誤說明與重試入口。
- **必須**：已取消或已逾時查詢的回應不再套用。

#### 錯誤與完成

- **預設**：錯誤留在受影響的欄位、區塊或頁面，交代原因與修正或重試方式，直到問題解決或開始下一次操作。
- **預設**：原處已有完整錯誤說明時，不再重複顯示 toast。
- **預設**：表單送出後的欄位驗證失敗，依表單順序將焦點移到第一個錯誤欄位，各錯誤欄位旁保留說明。
- **必須**：背景更新失敗不移動使用者目前的焦點。
- **預設**：簡短成功 toast 停留 5 秒，可提前關閉；滑鼠移入或鍵盤焦點停留時暫停自動消失。
- **預設**：資料讀取與背景更新成功，不顯示成功 toast。

### 操作確認

- **必須**：不可復原的資料刪除先確認；取消關注與可反向操作的處理狀態切換直接執行。
- **必須**：把已儲存且非空白的整段文字改成空白並送出時，先確認清空後果；一般修改與原本空白的內容不額外確認。
- **預設**：確認視窗以問句為標題，寫出影響對象與後果，送出按鈕使用具體動作名稱。
- **必須**：若能力提供清空整類資料或刪除帳號，使用者須輸入完整動作名稱，才能送出；單筆刪除與清空單篇文字維持一般確認。

## 前台

### 版面

- **預設**：前台是親和、安靜的投資記帳工具，總覽突出重要數字，清單較緊湊以方便比較。
- **預設**：淡漸層用於總覽與導覽，表格、圖表繪圖區及表單使用白色或近白色的中性底色。
- **預設**：依可用寬度切換版面，小於 960px 使用窄版導覽與字級，960px 起使用寬版側欄與字級；各頁內容另依需要調整排列。
- **必須**：頁面本身不橫向捲動。
- **預設**：窄版的一般資料清單改為多行排列，需要跨欄比較的表格保留欄位結構，在自己的容器內橫向捲動。

### 卡片與分組

- **預設**：先以標題、對齊、間距與細分隔線組織內容。
- **預設**：同頁包含不同用途、需要各自閱讀的資訊區塊時，可以使用卡片，例如市場行情、個人資產與近期交易。
- **預設**：同一摘要的個別數字、同類紀錄的各筆資料與同一表單的欄位，不逐項分卡；同一組資料的圖表與明細，不因呈現形式不同就分成不同卡片。
- **預設**：卡片內使用平面排版，避免再嵌套卡片。
- **預設**：改為單欄時移除一般資訊卡的容器外觀，以標題、間距與分隔線保留分組。
- **預設**：互斥選項各自包含多項需整組閱讀與選擇的資訊時，可以各自成卡，單欄時也可保留，例如方案選擇；一般紀錄上的編輯或刪除按鈕不構成這個例外。
- **預設**：一般卡片以底色、間距與必要細線建立層次，陰影主要用於對話框、選單等浮層。

### 字級與顏色

以下為預設字級，重要數字與標題可依資訊層級放大；寬版圖表沿用既有元件字級。

| 用途 | 寬版 | 窄版 |
| --- | ---: | ---: |
| 正文、表單輸入 | 16px | 16px |
| 主要操作按鈕 | 16px | 14px |
| 表格／清單資料、欄名 | 14px | 14px |
| 日期、股票代號與輔助文字 | 12px | 11px |
| 導覽文字 | 沿用既有元件 | 11px |
| 圖表刻度 | 沿用既有元件 | 11px |

- **預設**：藍色主要用於操作、選取狀態與圖表資料系列，中性摘要數字以位置、字級與字重突出。

### 漲跌

- **預設**：數值中的紅綠色限於漲跌、損益與報酬率，紅色代表上漲或獲利，綠色代表下跌或虧損，零值使用中性色；一般股價、成本、投入金額、股數與單筆現金股利使用中性色。
- **預設**：行情漲跌搭配 ▲／▼，損益與報酬率搭配正負號。
- **必須**：錯誤或破壞性操作使用紅色時，搭配明確文字與圖示，讓使用者能與行情上漲區分。

### 數字

- **預設**：金額摘要與交易紀錄附貨幣符號或「元」，數量附「股／張」，百分比附 `%`；行情股價可在欄名或區塊標題統一標示「元」，圖表由座標軸標示單位。
- **必須**：窄版重排後仍保留可見的單位標示。
- **預設**：股價與成交單價保留有效小數位，省略尾端的零。
- **預設**：彙總金額四捨五入到整數顯示。
- **預設**：平均成本等計算出的每股金額，最多顯示兩位小數並省略尾零。
- **預設**：投資相關百分比固定顯示兩位小數。
- **必須**：顯示格式與計算、儲存精度分開，顯示值不用於後續計算，既有計算規則依能力 spec。
- **預設**：個別缺值或不適用的數字使用 `--`，原因放在鄰近說明或可操作的資訊入口；同區域可集中說明原因，不能只靠滑鼠移入查看。

### 引導、動態與回饋

- **預設**：上手介紹搭配範例、圖解或插圖及開始操作的入口，說明服務用途與核心流程；個別功能的引導保持簡短，符合當下任務。
- **預設**：歡迎頁與上手介紹的文案可以更親切、帶有鼓勵語氣，日常功能維持直接、精確。
- **預設**：日常資料、表單與清單的動態用於操作回饋、狀態變化與必要轉場。
- **預設**：上手介紹與品牌區域可以使用輕量裝飾動畫，也可緩慢循環；資料區不使用裝飾性循環動畫。
- **預設**：使用者主動新增、編輯或刪除資料成功後，顯示簡短成功 toast。
- **必須**：操作受限時，說明限制種類、影響與適用的下一步；限制內容依相應能力 spec。

## 後台

- **預設**：以目前後台實作為視覺基準，維持高資訊密度、精確數字、克制層次與系統字型，不套用前台的新字級表。
- **預設**：字級與間距沿用 `frontend/src/pages/Admin/components.module.scss`、`Admin.module.scss` 及既有後台元件，圖表沿用 `frontend/src/pages/Admin/chart.ts` 的共用樣式。
- **預設**：後台依可用寬度調整同一套版面，780px 起使用可收合側欄，較窄時導覽移至上方、內容改為單欄。
- **預設**：以灰階為主，藍色用於互動、選取、圖表資料系列與提醒數量標記，區塊以細線分隔，不使用裝飾性陰影。
- **預設**：資料表使用固定表頭的捲動容器，依能力 spec 決定資料範圍與載入方式。
- **預設**：表格由表頭統一標示單位，圖表由座標軸標示單位，摘要與 tooltip 自行附單位；表頭及單位在捲動時保持可見。
- **預設**：各指標的小數精度依能力 spec，不能套用前台投資百分比的兩位小數規則。
- **預設**：缺值或不適用的數字使用 `--`；「進行中」等統計狀態使用文字，必要時附期間或結算日期。
- **預設**：管理操作成功後優先就地更新狀態，結果無法在目前畫面確認時，才補成功 toast。
- **預設**：文案可以使用 DAU、WAU、MAU 等分析工具術語。
