# 使用統計

使用統計讓開發者知道有多少使用者在使用 Taigu，以及他們用哪個平台使用 Taigu。前端在使用者使用 Taigu 時通知後端，後端記下每位登入的使用者在哪幾天、用哪個平台使用過 Taigu，這些紀錄在本文件稱為使用紀錄。

## 需求

### USAGE-R1 記錄使用 Taigu 的日期與平台

已登入的使用者在下面這些時候，前端把這位使用者正在用的平台傳給後端，後端記下這位使用者在這一天用這個平台使用過 Taigu，一天以台灣時間計算：

- 畫面開始顯示 Taigu 裡要登入才能使用的頁面（哪些頁面要登入才能使用見 ACCT-R3），不過後台 `/admin` 底下的頁面（見 ADMIN-R1）除外。

  開啟或重新整理這種頁面、登入後畫面換到這種頁面，以及在 Taigu 裡換到這種頁面，都算開始顯示這種頁面。

  > 設計理由：後台的頁面不算使用 Taigu，因為開啟後台是開發者在看統計與處理問題回報，不是使用 Taigu 記帳。完整討論見 [0004](../plans/archive/0004-admin-console.md)。

- 使用者切回顯示這種頁面的瀏覽器分頁或 PWA。

  切回指的是這個分頁或 PWA 原本看不到，又重新顯示在畫面上，例如使用者從其他分頁切回 Taigu 的分頁、從其他 app 切回 PWA，或解鎖手機之後看到 Taigu。

平台分成網頁與 PWA：Taigu 安裝成 PWA、在自己的視窗裡執行，畫面上沒有瀏覽器的網址列時是 PWA，在瀏覽器的分頁裡執行時是網頁，由前端判斷是哪一個平台。後端替同一位使用者在同一天、同一個平台只記下一筆使用紀錄。記錄沒有成功時，除了登入狀態結束的情況（處理方式見 ACCT-R5），畫面不顯示錯誤提示，正在顯示的頁面照常運作。

- USAGE-R1.1 在網頁上開啟 Taigu
  - 前提：使用者已經登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：在瀏覽器裡開啟儀表板 `/`。
  - 結果：後端記下這位使用者在 2026/10/24 用網頁使用過 Taigu。
- USAGE-R1.2 以 PWA 開啟 Taigu
  - 前提：使用者已經把 Taigu 安裝成 PWA 並登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：從裝置的主畫面開啟安裝成 PWA 的 Taigu。
  - 結果：後端記下這位使用者在 2026/10/24 用 PWA 使用過 Taigu。
- USAGE-R1.3 直接開啟設定頁
  - 前提：使用者已經登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：在瀏覽器裡直接開啟設定頁 `/settings`。
  - 結果：後端記下這位使用者在 2026/10/24 用網頁使用過 Taigu。
- USAGE-R1.4 登入後換到儀表板
  - 前提：使用者未登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：在瀏覽器裡開啟儀表板 `/`，畫面換到歡迎頁之後，用 Google 帳號登入。
  - 結果：畫面換到儀表板，後端記下這位使用者在 2026/10/24 用網頁使用過 Taigu。
- USAGE-R1.5 同一天再次開啟
  - 前提：後端已經記下使用者在 2026/10/24 用網頁使用過 Taigu。
  - 動作：同一天在瀏覽器裡重新整理儀表板。
  - 結果：這位使用者在 2026/10/24 用網頁使用 Taigu 的使用紀錄仍然只有一筆。
- USAGE-R1.6 同一天用兩個平台開啟
  - 前提：使用者在瀏覽器與 PWA 裡都已經登入，後端已經記下使用者在 2026/10/24 用網頁使用過 Taigu。
  - 動作：同一天從裝置的主畫面開啟安裝成 PWA 的 Taigu。
  - 結果：這位使用者在 2026/10/24 有網頁與 PWA 各一筆使用紀錄。
- USAGE-R1.7 隔天切回一直開著的分頁
  - 前提：使用者在台灣時間 2026/10/24 23:50 在瀏覽器裡開啟儀表板，之後切到其他分頁，沒有關閉 Taigu 的分頁。
  - 動作：台灣時間 2026/10/25 00:10 切回 Taigu 的分頁。
  - 結果：後端記下這位使用者在 2026/10/25 用網頁使用過 Taigu。
- USAGE-R1.8 隔天在 Taigu 裡換頁
  - 前提：使用者在台灣時間 2026/10/24 23:50 在瀏覽器裡開啟儀表板，之後 Taigu 的分頁一直顯示在畫面上，使用者沒有切到其他分頁。
  - 動作：台灣時間 2026/10/25 00:10 點導覽列的「市場」。
  - 結果：後端記下這位使用者在 2026/10/25 用網頁使用過 Taigu。
- USAGE-R1.9 日期以台灣時間計算
  - 前提：使用者已經登入，台灣時間 2026/10/24 與 2026/10/25 都還沒使用過 Taigu，現在是台灣時間 2026/10/25 07:30，也就是 UTC 2026/10/24 23:30。
  - 動作：在瀏覽器裡開啟儀表板。
  - 結果：後端記下這位使用者在 2026/10/25 用網頁使用過 Taigu，沒有記下 2026/10/24。
- USAGE-R1.10 開啟不用登入就能看的頁面
  - 前提：使用者已經登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：在瀏覽器裡開啟隱私權政策 `/privacy-policy`。
  - 結果：後端沒有記下這位使用者在 2026/10/24 使用過 Taigu。
- USAGE-R1.11 離線時切回分頁
  - 前提：使用者已經登入，在瀏覽器裡開著儀表板，切到其他分頁之後，裝置的網路中斷。
  - 動作：切回 Taigu 的分頁。
  - 結果：畫面沒有出現錯誤提示，儀表板照常顯示。
- USAGE-R1.12 隔天從其他 app 切回 PWA
  - 前提：使用者在台灣時間 2026/10/24 23:50 從裝置的主畫面開啟安裝成 PWA 的 Taigu，畫面顯示儀表板，之後切到其他 app，沒有關閉 PWA。
  - 動作：台灣時間 2026/10/25 00:10 從其他 app 切回 PWA。
  - 結果：後端記下這位使用者在 2026/10/25 用 PWA 使用過 Taigu。
- USAGE-R1.13 記錄失敗之後換頁
  - 前提：使用者已經登入，在瀏覽器裡開著前一天開啟的儀表板，台灣時間 2026/10/24 還沒使用過 Taigu；2026/10/24 裝置的網路中斷時，使用者切回 Taigu 的分頁，這次記錄沒有成功。
  - 動作：網路恢復之後，點導覽列的「市場」。
  - 結果：後端記下這位使用者在 2026/10/24 用網頁使用過 Taigu。
- USAGE-R1.14 登入狀態到期之後切回分頁
  - 前提：使用者在登入滿 30 天之前，在瀏覽器裡開啟設定頁 `/settings`，之後切到其他分頁，沒有關閉 Taigu 的分頁。
  - 動作：登入滿 30 天之後，切回 Taigu 的分頁。
  - 結果：畫面換到歡迎頁 `/welcome`，沒有出現錯誤提示；使用者重新登入後，畫面換回 `/settings`。
- USAGE-R1.15 開啟後台
  - 前提：使用者是 superuser，已經登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：在瀏覽器裡開啟後台的使用情況頁 `/admin/usage`，在後台裡換到訂閱頁，之後切到其他分頁，再切回後台的分頁。
  - 結果：後端沒有記下這位使用者在 2026/10/24 使用過 Taigu。
- USAGE-R1.16 從設定頁進入後台
  - 前提：使用者是 superuser，已經登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu。
  - 動作：在瀏覽器裡開啟設定頁 `/settings`，點「管理」區塊的「後台」。
  - 結果：後端記下這位使用者在 2026/10/24 用網頁使用過 Taigu。
- USAGE-R1.17 從後台回到 Taigu
  - 前提：使用者是 superuser，已經登入，今天（台灣時間 2026/10/24）還沒使用過 Taigu，在瀏覽器裡直接開啟了後台的使用情況頁 `/admin/usage`。
  - 動作：點後台導覽的「回到 Taigu」。
  - 結果：畫面換到儀表板，後端記下這位使用者在 2026/10/24 用網頁使用過 Taigu。

> 設計理由：前端以畫面有沒有顯示要登入才能使用的頁面判斷使用者這一天有沒有使用 Taigu，而不是看後端有沒有收到這位使用者的任何 request，因為前端會在背景定時重新讀取行情，開著沒關的分頁每天都會送出 request，算出來的人數會偏高；也不是看使用者有沒有新增或修改資料，因為很多使用者開啟 Taigu 只是查看持股與行情，不算進去的話人數會偏低。使用者切回 Taigu 與在 Taigu 裡換頁也算使用，因為分頁可以一直開著好幾天，只在載入頁面時記錄的話，隔天切回分頁或在 Taigu 裡換頁的使用者不會被記下。完整討論見 [0003](../plans/archive/0003-usage-recording.md)。

### USAGE-R2 使用紀錄的保留期間

後端不會因為時間經過而刪除使用紀錄，使用者的帳號刪除時，後端一併刪除這位使用者的使用紀錄。

- USAGE-R2.1 帳號刪除
  - 前提：後端記下了使用者在 2026/10/24 用網頁使用過 Taigu。
  - 動作：開發者依使用者的要求刪除這個帳號。
  - 結果：這位使用者的使用紀錄全部刪除。

> 設計理由：使用紀錄保留到帳號刪除為止，而不是保留一段期間（例如 13 個月）之後只留每天的彙總數字，因為一筆使用紀錄只有使用者、日期與平台，沒有同樣保留到帳號刪除的交易紀錄那麼敏感，而且保留每位使用者的使用紀錄，開發者之後想到新的統計方式時，才能用過去的使用紀錄重算。完整討論見 [0003](../plans/archive/0003-usage-recording.md)。
