# 產品

本文件裡「定位」「目標使用者」「範圍」「不做的事」這幾節描述 Taigu 想成為的產品，包括還沒做出來的功能，每個 plan 都不能超出這幾節寫的範圍；「術語表」一節則描述 `main` 上的程式碼目前使用的詞。

## 定位

Taigu 是專為台股設計、介面簡潔的投資記帳服務，讓投資人記錄交易與現金股利、追蹤持股、分析收益，用來取代投資人自己維護的 Excel 試算表。介面使用台灣的繁體中文，手機與電腦上的使用體驗同樣重要。

標語是「專為台股設計，你的專業記帳幫手」。

## 目標使用者

Taigu 的目標使用者是投資台股的散戶，從剛入門的新手、學生到經常交易的投資人都包括在內。他們重視資料一目了然、隱私與速度。

## 範圍

- 記錄買賣交易與現金股利，查看歷史紀錄。
- 查看持股、市場行情、大盤指數與個股詳情。
- 管理自選股，替個股寫筆記。
- 擬定買賣計畫。
- 分析收益。
- 分析手續費，記錄券商退還的手續費折讓。
- 用 Google 帳號登入。
- 回報問題。
- 提供 Free 與 Standard 兩種方案。

### 方案

Free 方案的額度限制每月新增的交易紀錄與現金股利紀錄合計的筆數、每月新增的買賣計畫筆數，以及持股與自選股的檔數，行情每 10 分鐘更新一次。Standard 方案沒有額度，行情每 30 秒更新一次，使用者透過綠界（ECPay）訂閱付款。新使用者有 31 天的 Standard 試用期。

## 不做的事

- 不提供投資建議。

## 術語表

| 術語 | 定義 |
| --- | --- |
| 股票代號 | 台股的股票代號，例如 2330、0050。 |
| 股票清單 | Taigu 認得的上市櫃股票，只有清單上的股票能被搜尋與記錄，清單的更新見 MKT-R10。 |
| 股、張 | 成交數量的單位，1 張是 1,000 股。 |
| 交易日 | 證交所有開盤的日子。 |
| 昨收價 | 上一個交易日的收盤價。 |
| 漲跌、漲跌幅 | 漲跌是目前的價格或指數減去昨收價，漲跌幅是漲跌除以昨收價。 |
| 交易紀錄 | 一筆買進或賣出股票的紀錄。 |
| 現金股利紀錄 | 一筆領到現金股利的紀錄。 |
| 持股 | 使用者目前持有的股票，判斷方式見 HOLD-R1。 |
| 現金投入 | 一檔持股的庫存裡每一股的買進成本總和，算法見 HOLD-R2 與 HOLD-R3。 |
| 市值、目前市值 | 市值是一檔持股以目前的價格計算的價值，目前市值是所有持股的市值合計，算法見 HOLD-R4 與 HOLD-R9。 |
| 投入金額 | 所有持股的現金投入合計，見 PERF-R1。 |
| 實現損益 | 已經賣出的股數賺到或賠掉的價差，加上現金股利，算法見 PERF-R11 到 PERF-R13。 |
| 年化報酬率 | 依使用者的紀錄與市值算出的 XIRR，算法見 PERF-R5 到 PERF-R8。 |
| 自選股 | 使用者加入追蹤清單的股票，介面上叫「關注」。 |
| 買賣計畫 | 使用者替某檔股票設定的目標價格與數量，分成買進計畫與賣出計畫。 |
| 個股筆記 | 使用者替某檔股票寫的筆記。 |
| 重大消息 | 上市櫃公司在公開資訊觀測站發布的重大訊息，見 STOCK-R12。 |
| 手續費折讓 | 券商退還給使用者的一筆手續費，記錄金額與日期。 |
| 淨手續費 | 扣掉手續費折讓之後，使用者實際付出的手續費，算法見 FEE-R1。 |
| 方案 | Free 或 Standard，決定使用者的額度與行情更新的頻率。 |
| 額度 | Free 方案對每月新增的交易紀錄與現金股利紀錄合計的筆數、每月新增的買賣計畫筆數，以及持股與自選股的檔數設下的上限，見 BILL-R3 到 BILL-R7。 |
| 試用期 | 新使用者免費使用 Standard 方案的期間，見 BILL-R2。 |
