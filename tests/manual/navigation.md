# 前台導覽

## NAV-R1.1 第一次開啟桌面前台

需要確認 1280px 視窗下的預設版面與收合入口。

1. 在沒有既有 `main-nav-collapsed` 收合紀錄的瀏覽器，以 1280px 寬的視窗開啟 Taigu 儀表板 `/`。
2. 檢查側邊欄與內容。

預期：側邊欄寬度為 230px，導覽文字與操作名稱都顯示，頂端有收合按鈕。

## NAV-R1.2 收合與展開側邊欄

需要確認滑鼠操作下的收合寬度、圖示名稱、展開狀態與 Dashboard 排列。

1. 以 1280px 寬的視窗開啟 Dashboard `/`。
2. 確認側邊欄展開。
3. 確認 Dashboard 左側區塊與右側圓餅圖沒有重疊。
4. 點側邊欄頂端的收合按鈕。
5. 確認側邊欄只顯示頭像、展開按鈕與導覽圖示。
6. 把滑鼠移到導覽圖示、新增圖示或搜尋圖示上。
7. 確認 tooltip 顯示對應名稱。
8. 確認 Dashboard 左側區塊與右側圓餅圖沒有重疊。
9. 點展開按鈕。
10. 確認 Dashboard 左側區塊與右側圓餅圖沒有重疊。
11. 把視窗調整為 1536×768px，先收合再展開側邊欄。
12. 以 Chrome 逐步縮窄再放寬視窗，並確認沒有出現 runtime error。
13. 確認 Dashboard 投入金額圖表、右側圓餅圖與摘要卡片沒有重疊。
14. 收合側邊欄，確認導覽、新增與搜尋按鈕都是 48 × 48px，並確認頭像、展開按鈕與各圖示都位於側邊欄水平中央。
15. 把視窗調整為 1366px。
16. 確認 Dashboard 左側區塊與右側圓餅圖沒有重疊。
17. 把視窗調整為 1440px。
18. 確認 Dashboard 左側區塊與右側圓餅圖沒有重疊。

預期：

- 收合後側邊欄寬度為 64px，只顯示頭像、展開按鈕與圖示；導覽與操作仍可點擊，滑鼠移入或鍵盤焦點停留時會顯示名稱。
- 展開後側邊欄寬度恢復為 230px，並顯示導覽文字與操作名稱。
- 側邊欄展開時，1280px 與 1366px 的 Dashboard 區塊上下排列，1440px 的 Dashboard 區塊左右排列；側邊欄收合時，Dashboard 依可用寬度調整排列。
- 收合時，導覽、新增與搜尋按鈕都是 48 × 48px，頭像、展開按鈕與各圖示都位於側邊欄水平中央。
- 所有檢查狀態下，圓餅圖都不與左側區塊重疊，頁面沒有水平捲動。
- 視窗縮窄與放寬時，瀏覽器沒有顯示 runtime error。

## NAV-R1.3 用鍵盤收合與展開

需要確認鍵盤操作、焦點與 `aria-expanded` 狀態。

1. 以至少 960px 寬的視窗開啟前台頁面。
2. 把鍵盤焦點移到側邊欄頂端的收合按鈕，按 Enter，再按一次。
3. 把焦點移回按鈕，按一次 Space，再按一次。

預期：每次操作切換收合狀態，按鈕的 `aria-expanded` 與畫面一致，焦點有清楚的可見輪廓。

## NAV-R1.4 切頁與重新載入後保留狀態

需要確認收合偏好在切換前台頁面與重新載入後保留。

1. 在同一個瀏覽器把側邊欄收合。
2. 切到市場頁 `/market`。
3. 重新載入頁面。

預期：切頁與重新載入後側邊欄都維持收合。

## NAV-R1.5 捲動主內容時固定側邊欄

需要確認主內容與側邊欄使用各自的捲動容器。

1. 以至少 960px 寬的視窗開啟內容超過一個視窗高度的頁面，確認側邊欄展開。
2. 用滑鼠滾輪或觸控板捲動主內容。
3. 把滑鼠移到超過可用高度的側邊欄並捲動側邊欄。

預期：主內容上下捲動時側邊欄維持在視窗左側原位；捲動側邊欄不會帶動主內容。

## NAV-R1.6 窄版的導覽不受收合狀態影響

導覽在不同可用畫面下的樣子要在真實瀏覽器裡確認，因為 jsdom 沒有版面。

1. 在 Chrome 以 1280 × 800 的可用畫面開啟儀表板 `/`。
2. 把側邊欄收合。
3. 用 DevTools 的裝置模擬把可用畫面改成 390 × 844。
4. 重新整理儀表板 `/`。
5. 把可用畫面改回 1280 × 800。

預期：390 × 844 時畫面有頁首與底部導覽列，沒有側邊欄與收合按鈕；改回 1280 × 800 後，側邊欄是 64px 寬的收合狀態。

## NAV-R1.7 收合功能的最小可用寬度

側邊欄的寬度要在真實瀏覽器裡確認，因為 jsdom 沒有版面。

1. 以 1280 × 800 的可用畫面開啟儀表板 `/`。
2. 確認側邊欄展開。
3. 用 DevTools 的裝置模擬把可用寬度改成 959px，高度維持 800px。
4. 把可用寬度改成 960px。

預期：959px 時側邊欄是 64px 寬的圖示列，頂端沒有收合按鈕；960px 時側邊欄恢復 230px 寬的展開狀態，頂端有收合按鈕。

## NAV-R2.1 手機直立

導覽在這個可用畫面下的樣子要在真實瀏覽器裡確認，因為 jsdom 沒有版面。

1. 用 DevTools 的裝置模擬把可用畫面設成 390 × 844。
2. 開啟儀表板 `/`。

預期：畫面底部有底部導覽列，左側沒有側邊欄。

## NAV-R2.2 平板直立

側邊欄的寬度要在真實瀏覽器裡確認，因為 jsdom 沒有版面。

1. 確認瀏覽器的 `localStorage` 裡沒有 `main-nav-collapsed`。
2. 用 DevTools 的裝置模擬把可用畫面設成 768 × 1024。
3. 開啟儀表板 `/`。

預期：左側的側邊欄是 64px 寬的圖示列，頂端沒有收合按鈕；畫面沒有底部導覽列。

## NAV-R2.3 手機橫放

導覽在這個可用畫面下的樣子要在真實瀏覽器裡確認，因為 jsdom 沒有版面。

1. 用 DevTools 的裝置模擬把可用畫面設成 844 × 390。
2. 開啟儀表板 `/`。

預期：畫面底部有底部導覽列，左側沒有側邊欄。

## NAV-R2.4 寬度跨過 600px

可用寬度改變時切換導覽，要在真實瀏覽器裡確認，因為 jsdom 沒有版面。

1. 以 1280 × 800 的可用畫面開啟儀表板 `/`。
2. 用 DevTools 的裝置模擬把可用寬度改成 599px，高度維持 800px。
3. 把可用寬度改成 600px。

預期：599px 時畫面有底部導覽列，沒有側邊欄；600px 時左側是 64px 寬的圖示列，畫面沒有底部導覽列。
