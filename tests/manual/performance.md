注意：這份檔案的指令會修改開發環境資料庫裡的資料，包括登入帳號的方案與共用的行情，所以要用只拿來測試的 Google 帳號登入，不要用存有真實資料的帳號。

執行 `make start`，在桌面瀏覽器（Chrome）開啟 `https://local.taigu.tw`，用 Google 帳號登入。下面指令裡的 `<email>` 換成登入用的 Google 帳號 email。

為了不被 Free 方案的額度擋下，第一次檢查前執行下面的指令，把帳號設成 Standard 方案：

```bash
docker compose -f compose.dev.yaml exec api-server python manage.py shell -c "from datetime import timedelta; from django.utils import timezone; from main.account.models import User; from main.billing.models import BillingProfile; now = timezone.now(); BillingProfile.objects.update_or_create(user=User.objects.get(email='<email>'), defaults={'plan': 'standard', 'subscription_status': 'active', 'current_period_started_at': now - timedelta(days=10), 'current_period_ends_at': now + timedelta(days=20)})"
```

如果新增交易紀錄時找不到 2330、2317 或 0050，執行下面的指令更新股票清單：

```bash
docker compose -f compose.dev.yaml exec api-server python manage.py update_company_list
```

每一段檢查都從沒有任何紀錄的帳號開始。注意，下面的指令會刪除這個帳號所有的交易紀錄、現金股利紀錄與手續費折讓：

```bash
docker compose -f compose.dev.yaml exec api-server python manage.py shell -c "from main.account.models import User; user = User.objects.get(email='<email>'); user.trade_records.all().delete(); user.cash_dividend_records.all().delete(); user.handling_fee_discount_records.all().delete()"
```

執行完上面的指令後，在 Chrome DevTools 的 Application 分頁點「Clear site data」，再重新登入，因為前端會在瀏覽器裡保存交易紀錄，之後只向 api-server 讀取有變動的部分。紀錄不多時，也可以改在畫面上逐筆刪除：交易紀錄與現金股利紀錄在歷史紀錄頁 `https://local.taigu.tw/records` 刪除，手續費折讓在手續費頁 `https://local.taigu.tw/handling-fee` 刪除。

PERF-R3 與 PERF-R4 的段落要在台灣時間 08:00 以後執行。

步驟裡的寫法另有以下約定：

- 「新增交易紀錄」指點側邊欄的「新增」，在「新增交易紀錄」視窗填好交易日期、股票、成交單價、買或賣、成交股數與手續費用後送出。步驟沒有寫手續費用時，保留預設值。
- 「新增現金股利」指點側邊欄「新增」右邊的三角形，選「新增現金股利」，填好交易日期、股票與現金股利後送出。
- 「新增手續費折讓」指在手續費頁 `https://local.taigu.tw/handling-fee` 點「新增折讓紀錄」，填好日期與折讓金額後送出。
- 「N 天前」指今天往前 N 天的日期，例如今天是 2026-10-21 時，365 天前是 2025-10-21。
- 「開啟儀表板」指點側邊欄的「儀表板」。在收益分析頁上點側邊欄的「儀表板」沒有反應，要改點頁面左上角的返回按鈕。
- 「開啟收益分析頁」指開啟儀表板後，點「實現損益」卡片。
- 走勢圖上一個點的日期與金額，在把滑鼠移到那個點上時顯示在提示框裡。
- 「設定價格」指先執行 `docker compose -f compose.dev.yaml stop scheduler`，讓 scheduler 不會蓋掉設定的價格，再執行下面的指令，把 `<股票代號>` 與 `<價格>` 換成段落指定的值，然後重新整理頁面。這一段檢查完之後，執行 `docker compose -f compose.dev.yaml start scheduler`。這個指令把行情的日期設成昨天，所以 15:00 寫入收盤價的工作不會把設定的價格當成今天的收盤價；不過它仍會改掉開發環境資料庫裡這檔股票的行情，所有帳號都看得到，而且要等 scheduler 在下一個交易日的盤中抓到行情才會更新回來；要保留原本的行情，先照 `tests/manual/stock-details.md` 準備步驟的做法備份，檢查完再還原。

  ```bash
  docker compose -f compose.dev.yaml exec api-server python manage.py shell -c "from datetime import date, timedelta; from main.market.models import StockInfo; print(StockInfo.objects.update_or_create(company_id='<股票代號>', defaults={'date': date.today() - timedelta(days=1), 'close_price': <價格>, 'fluct_price': 0, 'quantity': 1000000}))"
  ```
