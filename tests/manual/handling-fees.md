執行 `make start`，用 Chrome 開啟 `https://local.taigu.tw`，再用一個只拿來測試的 Google 帳號登入，因為下面有些步驟會刪除這個帳號的資料或改變方案。下面指令裡的 `<email>` 都換成這個 Google 帳號的 email，手續費頁的網址是 `https://local.taigu.tw/handling-fee`。

步驟寫「換成新帳號」時，照下面的做法取得一個沒有任何資料、還在試用期的新帳號。第 1 步會刪除這個帳號在本機資料庫的所有資料：

1. 執行 `docker compose -f compose.dev.yaml exec api-server python manage.py shell -c "from main.account.models import User; User.objects.filter(email='<email>').delete()"`。
2. 重新整理頁面。
3. 如果畫面沒有回到歡迎頁或登入頁，開啟 `https://local.taigu.tw/login`。
4. 用同一個 Google 帳號登入。

步驟寫「切換到行動裝置」時，在 Chrome DevTools 開啟裝置模擬（Toggle device toolbar），選 iPhone SE，再重新整理頁面。沒有寫的段落都在桌面瀏覽器上操作。

步驟寫「新增一筆交易紀錄」時，在桌面瀏覽器上點側邊欄的「新增」（不要點旁邊的 ▾），在出現的「新增交易紀錄」視窗填入步驟指定的交易日期，在「選擇股票」選 2330，「成交單價」填 100，「成交股數」填 1，最後把「手續費用」改成步驟指定的金額，再點送出按鈕。

步驟寫「新增一筆手續費折讓」時，在手續費頁點「新增折讓紀錄」，填入步驟指定的日期、折讓金額與備註，沒有指定的欄位維持原樣，再點送出按鈕。

長條的金額用游標移到長條上時出現的提示確認。
